กลับหน้าแอป

Database

✅ Supabase schema พร้อมใช้

profiles, books, user_library, reading_progress, bookmarks, reader_events

Security

✅ Row Level Security พร้อมใช้

reader เห็นข้อมูลตัวเอง, librarian/admin จัดการข้อมูลตามสิทธิ์

Auth

✅ Auth service พร้อมเชื่อม Supabase

Email, Register, Google OAuth, session, profile

Books

✅ Books service พร้อมใช้

ค้นหา เพิ่ม แก้ไข archive ลบ และหมวดหมู่

Library

✅ Borrow/Return service พร้อมใช้

ยืม คืน อ่านจบ archive และ admin loan list

Progress

✅ Progress service พร้อมใช้

บันทึกหน้า เปอร์เซ็นต์ อ่านจบ และ event

Bookmarks

✅ Bookmark service พร้อมใช้

สร้าง แก้ไข ลบ และผูก analytics

Frontend Integration
