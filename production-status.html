Production setup

หน้านี้เป็น fallback สำหรับ Demo Mode

เมื่อเพิ่มข้อมูลหนังสือจริง ให้ตั้งค่า flipbook_url ของหนังสือแต่ละเล่มเป็นลิงก์ไฟล์ PDF, flipbook หรือ reader page ที่ต้องการ

สำหรับการเชื่อมระบบจริง ให้ตั้งค่า environment variables ต่อไปนี้ในไฟล์ .env หรือ hosting provider:

  • VITE_SUPABASE_URL
  • VITE_SUPABASE_ANON_KEY
